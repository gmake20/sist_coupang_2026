# 동영상 시연 목록 (andy 담당 파트)

`docs/andy.md` 커밋 이력 기준으로, 실제 사용자 흐름을 따라가는 순서로 정리했습니다.
**핵심**은 꼭 넣고, **선택**은 시간 되면 추가하는 걸 추천합니다.

---

## 핵심 (꼭 넣기)

### 1. 판매자 회원가입 → 입점심사
- 판매자 회원가입 → 로그인 (아직 "입점 대기" 상태 확인)
- `/vendor/business-info`에서 사업장정보/정산계좌/서류첨부 제출 → "심사 중"으로 전환되는 것 확인
- (관리자 계정으로 전환) `/admin/sellers`에서 대기 목록 확인 → 상세보기 → **승인 처리** → 판매자로 다시 로그인해서 정상 이용 가능해진 것 보여주기

### 2. 상품 등록 → 관리자 승인
- `/vendor/product/write`에서 카테고리 선택, 옵션(이미지 업로드 포함), 배송정보 입력해서 등록 → "승인 대기" 상태
- 관리자 화면에서 상품 승인 처리
- `/vendor/product`(상품 목록)에서 노출/숨김, 판매중지/재개 토글

### 3. 상품 옵션 관리
- `/vendor/product/options` — 재고수량/판매가/품절여부를 표에서 바로 수정하는 것 시연

### 4. 주문/배송 → 정산까지 이어지는 흐름 (가장 임팩트 있는 파트)
- (구매자 계정으로 짧게 전환해서) 상품 하나 실제 주문
- `/vendor/order`로 돌아와서 방금 들어온 주문 확인 + 검색필터(주문상태/배송상태/결제상태/주문일) 한 번 걸어보기
- `/vendor/shipping`에서 "출고 대기" 목록 확인 → 송장번호 입력해서 출고 처리
- `/vendor/delivery`에서 "배송 중" 목록 + 지연 배지 보여주기
- (관리자 화면에서) 배송완료 처리
- `/vendor/settlement`에서 정산내역 리스트 → 상세보기(`/vendor/settlement/detail`)로 들어가서 주문별 내역 + 입금계좌 정보까지 확인

### 5. 판매자 대시보드
- `/vendor/dashboard` — 오늘 주문수/매출/방문자수/상품노출수 카드, 매출 현황 그래프(일간 탭 눌러서 실데이터 갱신 보여주기), 주문/배송 현황 패널

---

## 선택 (시간 되면 추가)

- 관리자 `/admin/vendor-action-logs` — 판매자 액션 로그 + 검색 기능(스토어명/액션종류/기간)
- 판매자 탈퇴 기능 (실제로 탈퇴하면 계정이 사라지니, 테스트 계정으로만 시연하거나 화면만 보여주고 실행은 생략 추천)
- CI/CD 배포 자동화 — Slack에서 `/restart` 명령 쳐서 서버 재시작되는 것 (화면 녹화 또는 캡처)

---

## 우선순위 메모

전체를 다 넣으면 길어지니, **1번(입점심사)**과 **4번(주문→배송→정산 흐름)** 두 개가 "여러 테이블을 오가는 흐름을 설계했다"는 소개 문구와 가장 잘 맞아서 이 둘을 중심으로 두고 나머지는 짧게 훑는 걸 추천합니다.
