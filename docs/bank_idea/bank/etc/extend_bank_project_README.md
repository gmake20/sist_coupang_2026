# 🏦 은행 웹 프로젝트

Java/Spring 기반의 은행 웹 서비스를 구현하는 학원 최종 프로젝트입니다.

실제 은행에서 제공하는 주요 업무를 참고하여 **회원, 계좌, 이체, 금융상품, 대출, 고객센터, 관리자** 등의 기능을 구현하는 것을 목표로 합니다.

# 4. 계좌이체

은행 프로젝트의 핵심 기능입니다.

```text
출금계좌
    ↓
이체금액
    ↓
입금계좌
    ↓
이체 처리
```

## 기본 이체

- 출금계좌 선택
- 입금계좌 입력
- 예금주 확인
- 이체금액 입력
- 계좌 비밀번호 확인
- 잔액 확인
- 이체 실행
- 이체 결과 출력

## 추가 기능

- 자주 쓰는 계좌
- 최근 이체 계좌
- 이체 한도
- 예약 이체
- 자동 이체

### DB Transaction

계좌이체는 여러 DB 작업을 하나의 Transaction으로 처리합니다.

```text
출금계좌 잔액 UPDATE
        ↓
입금계좌 잔액 UPDATE
        ↓
출금 거래내역 INSERT
        ↓
입금 거래내역 INSERT
        ↓
COMMIT
```

중간에 오류가 발생하면 전체 작업을 `ROLLBACK`합니다.

 ├─ MEMBER_ID
 ├─ LOGIN_ID
 ├─ PASSWORD
 ├─ NAME
 ├─ PHONE
 ├─ EMAIL
 ├─ ADDRESS
 ├─ ROLE
 └─ REGDATE

ACCOUNT
 ├─ ACCOUNT_ID
 ├─ MEMBER_ID
 ├─ ACCOUNT_NO
 ├─ ACCOUNT_PASSWORD
 ├─ BALANCE
 ├─ STATUS

# 22. 프로젝트 목표

최종적으로 다음과 같은 흐름을 완성하는 것을 목표로 합니다.

```text
회원가입
   ↓
로그인
   ↓
계좌 개설
   ↓
계좌 조회
   ↓
입금 / 출금
   ↓
계좌이체
   ↓
거래내역 확인
   ↓
금융상품 조회
   ↓
예금 / 적금 가입
   ↓
대출 신청
   ↓
관리자 심사
```

또한 관리자 시스템에서는

```text
관리자 로그인
     ↓

     ↓
계좌 관리
     ↓
거래 관리
     ↓
상품 관리
     ↓
대출 심사
     ↓
게시판 관리
     ↓
시스템 로그
```

를 수행할 수 있도록 구성합니다.
